🚨 Security Findings & Vulnerability Register

OF-SEC-001: Unauthenticated Information Disclosure in Debug Endpoint Critical

Location: backend/app/api/routes/analysis.py (Lines 366-368)

GET /analysis/debug_errors is completely unauthenticated and returns the global RECENT_ERRORS array, exposing system paths, SQL queries, and full Python stack traces to any anonymous requester.

Remediation: Remove /analysis/debug_errors from production builds or enforce strict admin authentication.
OF-SEC-002: Insecure CORS Wildcard with Credentials Allowed Critical

Location: backend/app/main.py (Lines 30-50)

CORSMiddleware has allow_origins=["...", "*"] with allow_credentials=True. Browsers reject wildcard origins when credentials are exchanged, but permissive clients or proxies can leak authenticated data to malicious cross-origin websites.

Remediation: Remove "*" from allow_origins. Explicitly list only your approved domains.
OF-SEC-003: Broken Auth Fallback to Mock User in get_current_user High

Location: backend/app/api/dependencies.py (Lines 83-107)

get_current_user delegates to get_optional_user, which returns a hardcoded mock user UserInfo(uid="default_doctor", role="doctor") if the token is missing. Unauthenticated callers automatically receive doctor privileges.

Remediation: Update get_current_user to depend directly on verify_token (returning 401 Unauthorized when tokens are missing or invalid).
OF-SEC-004: Insecure Direct Object Reference (IDOR) in Case History High

Location: backend/app/api/routes/analysis.py (Lines 380-400)

In GET /analysis/history, if the requesting doctor has 0 records, the API executes a fallback query returning the cases of all other doctors in the clinic.

Remediation: Remove the global fallback query. Return an empty list [] when no records belong to the user.
OF-SEC-006: Unauthenticated Static Directory Serving of Medical Images High

Location: backend/app/main.py (Lines 55-56)

app.mount("/uploads", StaticFiles(directory="uploads")) exposes all patient radiographs and photos publicly without authentication.

Remediation: Stream medical images through an authenticated API endpoint or use short-lived signed URLs from Firebase Cloud Storage.
